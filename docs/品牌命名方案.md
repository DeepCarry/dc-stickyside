### 二、品牌命名理念

#### 中文：随手贴

名称由「随手」和「贴」组成。

「随手」体现快速、自然、低操作成本的工作习惯。

「贴」对应真实办公场景中的便利贴，让用户自然联想到把一张纸贴在桌面、显示器或者办公区域，随时提醒自己。

**随手贴的核心含义：有事随手贴，需要随时看。**

它可以用于记录临时任务、重要提醒、长期 Checklist、工作灵感、常用文字、截图及其他零散信息。

#### 英文：StickySide

名称由 `Sticky` 和 `Side` 组成。

- **Sticky**：让英语用户联想到 sticky notes（便利贴）。
- **Side**：代表屏幕侧边，与产品的侧边悬浮便签功能对应。
- **StickySide**：作为组合品牌名称，表达「把重要内容放在屏幕手边」的产品理念。

英文名称采用简短的组合词形式，便于设计 Logo、应用图标和国际化品牌视觉。

**语言说明：** StickySide 属于自创组合词，其含义主要通过产品场景、图标和品牌描述建立。它不属于英语中的固定表达。正式发布前应进行英语母语者理解测试和商标查重。

### 四、产品定位

**中文定位**

随手贴是一款专为 macOS 打造的轻量级便签与桌面效率工具。它让用户像使用真实便利贴一样，快速记录任务、提醒、清单、文字和图片，并通过屏幕边缘便签与便签墙，随时查看和取用重要信息。

**English Positioning**

StickySide is a lightweight sticky notes and productivity app for macOS. Capture quick thoughts, tasks, reminders, checklists, text, and images in seconds. Keep important notes within easy reach using a convenient screen-edge panel and a visual note wall.

### 五、产品核心价值

**1. 随手记录 / Quick Capture**

快速创建便签，记录临时任务、想法、重要信息和截图。

**2. 随时查看 / Always Within Reach**

利用屏幕边缘悬浮便签，减少在多个应用窗口之间寻找信息的操作。

**3. 灵活管理 / Flexible Organization**

支持彩色便签、纯文字、图片、图文混排和待办清单，适应临时和长期使用场景。

**4. 随取随用 / Instant Access**

把邀请码、常用文字、临时资料和重要信息放在便签中，需要时快速复制、粘贴和使用。

**5. 轻量高效 / Lightweight Productivity**

围绕 macOS 的多窗口、多桌面及多显示器工作方式优化日常便签体验。

### 九、品牌视觉建议

**品牌气质**

- 简洁、现代、轻量
- 亲切、实用、富有活力
- 符合 macOS 桌面应用的审美
- 保留真实便利贴的直觉体验

**Logo 设计方向**

以「便签纸 + 屏幕边缘 + 轻巧的固定动作」为主要视觉元素。

推荐探索一张圆角小便签依附在屏幕边缘的抽象图形，保持小尺寸图标的识别能力。

颜色可以延续当前产品界面中的柔和便签配色，例如浅黄、薄荷绿、淡蓝和淡紫，以一种主品牌色建立统一识别。
