三态规格Three states, one movement

一个由鼠标驱动的状态机：静止 → 扇开 → 抽出。所有尺寸为正式实现的点值。
铁律：贴屏幕的那一侧永远是直线、零缝隙——三种形态都只向屏幕内侧生长， 倾斜与层次只发生在外侧边缘。

时序与防误触

0 ms指针进入细条 → 立即开始扇开（唯一主动触发，不设延迟：来都来了）
45 ms × n第 n 张签的级联延迟，整套展开约 0.3s
320 ms指针离开后延迟 320ms 才收拢——防止在签和屏幕边之间来回扫时闪烁（Noty 同款节奏）
280 ms点击签 → 抽出面板弹簧滑入，从签的纵向位置出发
250 ms打字停手 250ms 后写盘（记的是「你停下来」，不是每个按键）

模式与入口哪些便签会出现在边缘上

你定的方向：两种模式都要——既能自动看最新的，也能专门钉几张常驻。

最近模式 自动

按 最近编辑时间自动取前 N 张（默认 8，可设 4–12）。零管理成本， 每次顺手记一条、改一句，它就在边缘上。编辑让它浮到最上面，不动的慢慢沉下去。

updatedAt 排序 上限可调 4/6/8/10/12 锁定自动消失

钉住模式 手动

只显示你逐张钉上去的便签，按钉的时间从早到晚排列。 适合「这周每天都看」的那几张：报价底线、部署步骤、周报模板。 钉/取消钉在卡片「⋯」菜单里，可撤销。

安全与边界把丑话说在前面

边缘条是把内容直接画在屏幕上的组件，安全规则必须比主窗口更严。

🔒
锁定的便签绝不进边缘条

锁定的便签正文与图片在磁盘上是密文（AES-GCM），但边缘条要展示内容就必须持有明文。 规则：锁定那一刻立即从边缘条消失；edgeNotes 计算属性硬性排除 isLocked， 不是靠 UI 层「不显示」——数据层就不给。解锁定时器到期时若正被抽出展示，面板立即关闭。

🗑️
回收站与空便签不进边缘条

进了回收站的便签（deletedAt ≠ nil）和没有内容的便签同样被排除。 彻底删除的便签若正被抽出展示，面板立即关闭，不留一张「孤纸」。

⌨️
不抢焦点，但借键盘

边缘条与抽出面板都是 nonactivatingPanel：点击纸签不会把便签墙提到前台， 你正在写的周报窗口保持激活——光标却已落在抽出面板里，可直接打字（与 ⌥Space 捕获面板同一机制）。 Esc 收回、点面板外收回、右上角 ✕ 收回。

🖥️
多屏与换屏

首版只在主屏停靠一条。插拔屏幕（didChangeScreenParameters）时重新定位并校验可见性。 「每屏一条」是多屏用户的需求，留到后续版本——先把一条做稳。

✍️
编辑防抖与锁定竞态

抽出面板的编辑不直接绑存档：正文改动在本地暂存，停手 250ms 后写回， 写回时重新校验锁定态——如果这 250ms 里便签被自动上锁了，就丢弃这次写入， 绝不能把明文塞进已加密的便签里。

⚡
与捕获面板、刘海的关系

边缘条纵向居中，避开刘海与两翼入口的顶部区域；层级与捕获面板同为 floating， 互不遮挡（一个在屏幕中央、一个在边缘）。⌥Space 的全局快捷键不受影响。

待定决策点四个问题，每个都给了推荐

点选你认为对的选项（仅为记录倾向，最终以你的答复为准）。

D1 · 「最近」和「钉住」怎么共存？

你之前说"既能查看最新的，又能查看我专门让它显示在那里的"。落成产品有两条路：

两个独立模式，可切换（默认「最近」右键边缘条或设置里切换。心智简单：边缘条现在"是什么模式"很明确；两种内容不会互相挤占。 推荐 · 贴合原话
单一混合模式：钉住的排前面，其余位置用最近编辑补足不用切换，两种内容同时在场；但"补足"意味着钉住的会挤掉最新的，边缘条内容混合后不好预期。
D2 · 边缘条默认开还是关？
升级后默认关闭，设置里开启保守。老用户桌面右缘突然多一条东西，可能被当成"又来一个常驻组件"。
默认开启（首次启动时 Toast 提示一句"边缘条已就位，鼠标移过去看看"）功能的全部价值在"被发现"。一条 12pt 细条的存在感极低，打扰成本接近零，而关闭它只要一次右键。 推荐
D3 · 钉住模式下没钉任何便签时，边缘条显示什么？
显示一张米白色"空签"，竖排写着"还没有钉住的便签 · 在卡片菜单里钉一张"边缘条的存在感靠持续可见；空态是唯一的引导入口，藏着等于让用户自己猜。 推荐
完全隐藏，钉了第一张才出现更干净，但"切到钉住模式后边缘条不见了"容易被当成 bug。
D4 · 抽出面板的编辑范围？
纯文本编辑（正文 + 清单勾选语法照常可打）边缘场景追求快进快出，改一句话就走。图片展示但不在面板里换图；换纸色/标签/换墙这些低频操作回主窗口。 推荐 · 首版
完整编辑：换纸色、改标签、勾选框可点、清单 Enter 续行面板变高变复杂，接近把主窗口搬过来；这些能力目前主窗口也还没有（Enter 续行在待办清单里）。
